## [1.0.0] - 2026-10-02

First release under the shared versioning of the wissem.pro projects.

- Extraction of Ameli third-party payment statements (text PDFs) to JSON, without the insured person's name, NIR or address.
- Command line for one file or a folder, and a Python API.
- Validation status for results that need a manual check.
